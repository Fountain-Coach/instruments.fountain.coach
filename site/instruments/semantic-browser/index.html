What the instrument does

The instrument observes an admitted URL or preview host, captures a structured page snapshot, produces source-addressed semantic blocks, resolves a requested target, and returns a typed lifecycle event. Reframe owns mediation, source identity, host focus, AX, and FountainStore persistence.

Projections, not second authorities

WebKit / Source View

Shows the rendered page when admitted. Native Markdown/Fountain Source View remains authoritative.

MIDI2 Monitor

Mirrors the typed lifecycle and instrument event stream for inspection.

FountainStore

Persists snapshot, dissection, resolution, and terminal receipt evidence.
