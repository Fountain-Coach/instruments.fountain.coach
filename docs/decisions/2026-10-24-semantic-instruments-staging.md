# Instruments: semantic front-page replacement, staging first

**Owner intent:** Instruments should show the current artistic software capabilities Sing, Ear and SatzfunkPlayer rather than lead with the earlier Codex Login, Semantic Browser and Csound AUv3 technical catalogue. Start with three distinct logos, then explain the acts they perform and their actual acceptance states.

## Pinned facts

- Fountain-Coach/sing currently reports a native persistent PCM singing engine with typed MIDI 2.0 UMP note and expression events; accepted human intelligibility, physical MIDI connectivity and worst-case realtime performance remain outstanding.
- Ear has a source-proven AudioWorklet and locally observed Web Audio/Csound-to-MIDI2 event boundary in Reframe R12. No standalone, completed physical Ear MIDI2 instrument or iPad Safari acceptance is claimed.
- Fountain-Coach/SatzfunkPlayer has a private new Git project, with pure JavaScript binding/selection modules and eight passing tests. Semantic vision, frame extraction, actual image publication and MIDI 2.0 instrument admission remain pending.
- Prior Codex Login Instrument, Semantic Browser and Csound AUv3 pages are still original public content, preserved and linked in a secondary reference section. Their underlying packages are not declared deleted or technically obsolete.

## Visual semantics

Three source-owned SVG marks share one 256-square geometry, radius 48, quiet light field, charcoal line and restrained ochre point. **Sing** uses a vocal source with radiating resonance. **Ear** uses curved approaching wavefronts and a listening point. **SatzfunkPlayer** uses a composed still frame and playback position. No faces, pictorial clichés, invented loudspeaker app icon or third-party brand/marks. The same assets appear in the catalogue and may later be reused as editorial identity art; they are not certified trade marks.
